# Objetivo del proyecto
## Una aerolínea quiere conocer mejor sus tipos de clientes y segmentarlos en diferentes tipos. Para esto se suministra una base de datos con los datos demográficos y de consumo de cada uno
## Al hacer el análisis con 3 modelos de clusterización diferentes (K-Means, DBSCAN y HC / Hierarchical Clustering). Analizamos cada resultado de cada modelo y tomamos el que mejor interpretabilidad ofrece a la compañía

## Finalmente se le dan recomendaciones a la aerolínea usando los hallazgos encontrados en el proyecto y se sugieren hipotésis y estrategias para campañas de mercadeo personalizadas a los diferentes tipos de viajeros encontrados.
