# Project Objective

## An airline wants to better understand its types of customers and segment them into different types. For this purpose, a database containing the demographic and consumption data of each customer is provided.

## By conducting the analysis using 3 different clustering models (K-Means, DBSCAN and HC / Hierarchical Clustering), we analyze the results of each model and select the one that offers the best interpretability for the company.

## Finally, recommendations are provided to the airline based on the findings obtained from the project, and hypotheses and strategies are suggested for personalized marketing campaigns targeting the different types of travelers identified.
